# Contributing

Bug reports, ideas and pull requests are welcome.

- Contributions are accepted under the project's licence, MPL-2.0. By opening a pull request you agree to that.
- Keep the SPDX header and the copyright lines at the top of each file. Add your own line to a file you change a lot.
- Run `sh tests/run_tests.sh` before you open a pull request. Changes to sound should come with a host test.
- Don't add code from GPL projects. Code under MIT, BSD, Apache-2.0 or
  MPL-2.0 is fine with credit in CREDITS.md.

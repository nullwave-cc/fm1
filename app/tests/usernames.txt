# A user preset keeps its name (SAVE > USER, app.c user_t): saved with the sound's name, said as the slot turns, the
# channel named so when it loads, over a power-on, and with the song; a preset from the editor brings its own (tests/editor_test.py).
# Run by tests/run_tests.sh:
#   app/build/host/nullwave_host app/tests/usernames.txt app/build/host
wait 1800
